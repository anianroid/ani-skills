# Catalog (one line each)

Source: [growth.design/psychology](https://growth.design/psychology). Details in the bucket files. Traps in [traps.md](traps.md).

## Information — filter

- Hick's Law — more options, harder/slower decisions
- Confirmation Bias — seek/interpret what fits existing belief
- Priming — recent stimulus tilts the next judgment
- Cognitive Load — mental effort the task requires
- Anchoring Bias — first number/info dominates later judgment
- Nudge — small cue, no force
- Progressive Disclosure — complexity later
- Fitts's Law — big + near is faster to hit
- Banner Blindness — learned ignore of ad-shaped stuff
- Decoy Effect — inferior third option steers the pair
- Framing — wording/presentation moves the choice
- Attentional Bias — current thoughts/emotions steal gaze
- Empathy Gap — cold you under-predicts hot you
- Visual Anchors — designed landing spots for the eye
- Von Restorff Effect — the isolate is remembered
- Visual Hierarchy — designed reading order
- Selective Attention — focus makes the rest invisible
- Survivorship Bias — you only see what passed the filter
- Juxtaposition — GD line = near+similar group; ads = compare
- Signifiers — cues for what a control will do
- Contrast — attention follows visual weight
- External Trigger — next step is inside the prompt
- Centre-Stage Effect — middle option gets chosen
- Law of Proximity — near = related
- Tesler's Law — leftover complexity moves to the user
- Spark Effect — tiny effort, more action (Fogg Ability)
- Feedback Loop — after act, say what happened
- Expectations Bias — priors color what you see
- Aesthetic-Usability Effect — pretty feels easier

## Meaning — invent a story

- Social Proof — copy others when unsure
- Scarcity — limited feels valuable
- Curiosity Gap — missing info hurts; people fill it
- Mental Model — they already think they know how it works
- Familiarity Bias — prefer the known
- Skeuomorphism — real-world look eases new tech
- Reciprocity — give first, they return
- Singularity Effect — one person beats a statistic
- Variable Reward — unexpected reward holds
- Aha! moment — first time they feel the value
- Goal Gradient Effect — closer to the goal, faster
- Occam's Razor — fewer assumptions usually wins
- Noble Edge Effect — genuine care earns preference
- Hawthorne Effect — observed people change
- Halo Effect — one trait spills to the rest
- Miller's Law — working memory is tiny (chunks, not “7 menu items”)
- Unit Bias — one presented unit feels like enough
- Flow State — challenge/skill + clear goals + feedback
- Authority Bias — costume of expertise
- Pseudo-Set Framing — fake “set” demands completion
- Group Attractiveness — item/person looks better in a group
- Curse of Knowledge — experts can’t simulate novices
- Self-Initiated Triggers — user-authored prompts win
- Survey Bias — polite / led / socially desirable answers
- Cognitive Dissonance — two opposing ideas hurt
- Feedforward — show the consequence before the click
- Hindsight Bias — “I knew it” after the outcome
- Law of Similarity — same look = same group
- Law of Prägnanz — ambiguity resolves to the simplest whole
- Streisand Effect — hiding it advertises it
- Spotlight Effect — they think they’re watched more than they are
- Fresh Start Effect — temporal landmarks open new goals

## Time — act fast

- Labor Illusion — visible work raises perceived value
- Default Bias — people keep the pre-set
- Investment Loops — what they put in pulls them back
- Loss Aversion — losses hurt more than equal gains
- Commitment & Consistency — small yes, then stay consistent
- Sunk Cost Effect — past spend keeps them in
- Reactance — force creates the opposite
- Law of the Instrument — hammer → nails
- Temptation Bundling — want + should, together
- Dunning-Kruger Effect — novices overrate themselves
- Discoverability — can they find the move from the screen
- Second-Order Effect — consequences of the consequences
- Decision Fatigue — many prior choices, sloppier next one
- Observer-Expectancy Effect — researcher leaks the hypothesis
- Weber's Law — notice ratios, not raw deltas
- Parkinson's Law — work fills the time allowed
- Affect Heuristic — good/bad tag stands in for risk/benefit
- Hyperbolic Discounting — now >> later
- Chronoception — felt time ≠ clock time
- Cashless Effect — invisible money, more spend
- Self-serving bias — credit wins, blame the app
- Pareto Principle — vital few drive most effect
- Backfire Effect — rare; corrections usually just fail quietly
- False Consensus Effect — “everyone thinks like me”
- Bandwagon Effect — adoption begets adoption
- Barnum-Forer Effect — generic copy feels personally true
- IKEA Effect — I made it, so it’s worth more
- Planning Fallacy — this time will be faster (it won’t)

## Memory — keep a few bits

- Provide Exit Points — invite them to put it down
- Peak-End Rule — judged by peak + ending
- Sensory Appeal — more senses, stickier
- Zeigarnik Effect — unfinished stays available
- Endowment Effect — “mine” is overvalued
- Chunking — grouped bits beat a pile
- Delighters — unexpected play, after basics work
- Internal Trigger — a memory/feeling opens the app
- Picture Superiority Effect — pictures beat words (if literal + seen)
- Method of Loci — stable place helps retrieval
- Shaping — reinforce the next approximation
- Recognition Over Recall — show it; don’t make them remember it
- Storytelling Effect — stories beat fact lists
- Negativity Bias — one bad beats several goods
- Availability Heuristic — easy to recall feels common/likely
- Spacing Effect — gaps beat cramming for later memory
- Serial Position Effect — first and last of a list win
