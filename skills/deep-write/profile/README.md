# profile/ : the personal learning layer

This folder is where deep-write's self-evolution lives for one author. It holds
the rules the skill has learned from how you react to and use it.

- `LEARNED.md`: active, graduated rules applied on top of the shareable defaults.
- `signals.md`: the raw journal of observations.
- `CHANGELOG.md`: the audit trail of every change, so any of it can be reverted.

These three files are **gitignored**. They are personal and do not ship. When
deep-write is open-sourced, the engine (`references/evolution.md`) travels but
your data does not, and each new user grows their own profile from empty. This
`README.md` is tracked so the folder and its purpose ship with the skill.

See `../references/evolution.md` for how the loop works.
