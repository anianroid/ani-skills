# LinkedIn post template

Rules: native long-form, complete without a click. Hook in the first two lines
(before the ~210-character fold), leading with the contrarian number. Short
paragraphs with whitespace. No broetry. One 👇 and a closing question. Five
trailing hashtags. Link goes in the first comment, which you post yourself.

```
<Hook line 1: the contrarian setup with the number.>

<Hook line 2: concede the math, then turn it. This must land before the fold.>

<Context paragraph: what everyone is doing, in plain terms.>

<The first complication, with one linked-in-mind stat named in prose (Gartner
expects 40%+...). Keep paragraphs to one to three sentences.>

<The reframe as a short standalone line. "Boring is the moat.">

<The second point or the fork, if the piece has one. Keep it concrete.>

<The payoff line: what the reader should take away.>

<Aphoristic close, in prose.>

(Disclosure: <plain, disarming disclosure if you have a stake>.)

<One closing question to pull comments.> 👇

#Tag1 #Tag2 #Tag3 #Tag4 #Tag5
```

## First comment (post immediately yourself)

```
Full essay, with the data and the <thing> math: <link> short version: <one-line
recap of the thesis>.
```

## Optional: PDF carousel manifest

8 to 10 slides, 4:5 portrait, editorial style. Slide 1 is the hook, one idea per
slide mirroring the essay, link on the final slide. List the slide headlines here
so a human or an image tool can produce it.
