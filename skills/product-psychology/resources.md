# Product psychology resources

These five sit at the bottom of [growth.design/psychology](https://growth.design/psychology). Use them as lenses, not as a reading list to recite.

## Cognitive Biases Codex — Buster Benson (2016)

**Job:** Organize 175+ biases by the problem the brain is solving.

Four problems:

1. Too much information → filter (noise becomes signal)
2. Not enough meaning → fill gaps (signal becomes a story)
3. Need to act fast → jump (story becomes a decision)
4. Not enough memory → keep a few bits (decision trains the next filter)

Four costs: you miss useful info; you invent details; fast calls go selfish; memory makes the next pass worse.

John Manoogian III drew the circular poster. Growth.Design’s four buckets **are** this model.

Read: [Cognitive bias cheat sheet](https://buster.medium.com/cognitive-bias-cheat-sheet-55a472476b18)

## Super Thinking — Gabriel Weinberg & Lauren McCann

**Job:** Name the model so you can spot it. Toolbox for *choosing*, not for writing a CTA.

High-leverage models: first principles, inversion (“be wrong less”), Ockham, Hanlon, second-order effects, antifragility, outside view / reference class, unforced errors, MVP / de-risk assumptions.

Use when the question is “which principle applies?” or “what would make this fail?”

## Hooked — Nir Eyal

**Job:** Habit loop for products people *already want* to use.

```
Trigger → Action → Variable reward → Investment → (next trigger)
```

- External trigger: next step is *in the prompt* (email, badge, empty-state button).
- Internal trigger: a feeling fires the open (boredom → feed).
- Action must be simple (Fogg Ability).
- Variable reward creates craving; predictable feedback does not.
- Investment (data, setup, follows, content) loads the next trigger and raises switching cost.

Ethics: Manipulation Matrix — would I use it, and does it help the user? *Indistractable* is the user-side counterpart. Prefer self-initiated triggers over spray.

## Influence — Robert Cialdini (Coming Soon on the page)

**Job:** Compliance levers. Six original, Unity added in *Pre-Suasion* / 2021 edition.

| Lever | Honest product use | Dark twin |
|---|---|---|
| Reciprocity | Value before the ask | Fake gift that is a charge |
| Commitment & consistency | Tiny first yes the user means | Forced micro-yes then identity trap |
| Social proof | Real counts, similar others | Botted “12k joined” |
| Authority | Relevant expert, clickable attestation | White coat / SOC2 theater |
| Liking | Warm, specific, human | Fake founder intimacy |
| Scarcity | True limit | Resetting timers |
| Unity | Shared identity (“one of us”) | Fake community |

## Predictably Irrational — Dan Ariely (Coming Soon on the page)

**Job:** Lab patterns you can design around.

- Relativity / decoy (Economist print+web)
- Arbitrary anchors (first number sticks)
- Power of FREE (zero-price jump)
- Social vs market norms (a small payment kills the favor)
- Hot/cold empathy gap
- Ownership / endowment / IKEA
- Price-shaped placebo (expensive “works more”)
- Small-stakes dishonesty

Irrationality is systematic. That is a responsibility, not a license.
