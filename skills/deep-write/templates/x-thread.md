# X thread template

Rules: tweet 1 is link-free and leads with the contrarian number + 🧵. One idea
per numbered tweet, mirroring the essay sections. Genuine @-attribution inline.
Disclosure inline if you have a stake. Link only in the final tweet. No hashtags.
Attach a diagram to tweet 1 if you have one.

```
1/ <contrarian hook leading with the number. Concede the premise, then turn it.>
<one-line restatement of the thesis> 🧵

2/ <the "demo is the easy part" / first complication. One hook stat, linked idea.>

3/ <the concrete, specific claim. Short punchy fragments.>

4/ <mechanism or why. @-attribute the framework or author you're borrowing.>

5/ <the reframe. One more stat. Land a short aphoristic line.>

6/ <the decision or fork the popular take skips.>

7/ <the risk / the cost of the naive path. Specific numbers.>

8/ <the recommendation. Inline disclosure if you have a stake (I work on @x).>

9/ <the close: aphoristic antithesis.>
<link on this final tweet only>
```
